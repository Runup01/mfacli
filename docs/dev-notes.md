## 🧭 通用规则（下个项目直接复用）

> 格式：**规则**（一句话）→ ⚡ 为啥（坑）→ ✅ 怎么做。

### A. 版本与发布
- **A1 tag 推上去就别想删，冲突就 bump 版本。**
  ⚡ 平台 ruleset 默认禁删 tag，重推同名 tag 必被拒，来回折腾一下午。
  ✅ 发版前确认版本号没占用；被拒就 v0.1.10 → v0.1.11，别回头。
- **A2 文档安装入口永远指向最新版，发版不改文档。**
  ⚡ 链接里带版本号 = 每次发版都要改 README，忘一次用户就装旧版。
  ✅ 流水线上传**无版本别名包**（`mfacli_amd64.deb` 等），文档只用 `releases/latest/download/别名包`。
- **A3 版本号引用一次改全。**
  ⚡ Cargo.toml / Cargo.lock / README / install 文档 / CHANGELOG 五处，漏一处就是"文档说 0.1.9 包装出来 0.1.8"。
  ✅ 改版本用全局替换 + `rg -n "0\.1\.[0-9]+"` 复查。
- **A4 release 只能有一个写手。**
  ⚡ 多 job 并发 publish 同一个 release 会互相取消/冲突（真实发生过，3 个构建被取消）。
  ✅ 构建 job 只 upload-artifact，最后一个 job 下载汇总、统一发布。

### B. CI 与代码
- **B1 clippy 开 `-D warnings`，本地也要跑同样的命令。**
  ⚡ 本地只 warn、CI 才 error，发布当晚才发现就晚了。
  ✅ 提交前 `cargo clippy -- -D warnings`。
- **B2 函数参数超 7 个就收结构体。**
  ⚡ clippy 默认阈值 7（`too_many_arguments`），配置类函数最容易超。
  ✅ 收 `ConfigOpts` 式结构体，不写 `#[allow]`——以后加字段也不再碰限制。
- **B3 离线也能干活。**
  ⚡ 网络一断，没缓存的 crate 直接停摆。
  ✅ 日常 `cargo build/clippy --offline`；删依赖后 `cargo update --offline` 清 lock 孤儿包。

### C. 安全
- **C1 真实密钥一个字节都不进仓库。**
  ⚡ 真实发生过：测试时把真密钥 commit 上去了，只能轮换密钥 + 重建历史。
  ✅ examples 一律假数据（`JBSWY3DPEHPK3PXP`）；提交前 `git diff --cached` 扫一眼。
- **C2 不可逆操作先铺逃生绳。**
  ⚡ 应用锁忘密码 = 数据永久丢失，用户会回来骂。
  ✅ 启用前**强制**写明文备份 + 风险告知 + 二次确认，备份路径可一键复制。
- **C3 敏感能力默认关（opt-in）。**
  ⚡ 钥匙串免密这类"方便但扩大攻击面"的功能，默认开=替用户做主。
  ✅ 默认 off，`config --keychain on` 才开，提供单次绕过 `--no-keychain`。

### D. 文档与提示
- **D1 一种语言走到底，混用最丑。**
  ⚡ 中英混杂的 help 被用户点名批评。
  ✅ help 全英文、运行时提示全中文、文档中文为主。
- **D2 README 卖产品，docs 教动手。**
  ✅ README = 介绍 + 亮点表 + 快速开始；逐步细节去 docs/，互相链接。
- **D3 报错要教用户下一步。**
  ⚡ "invalid value" 不说能给啥，用户只能懵。
  ✅ 错误里带可选值/示例命令（clap 的 `possible values` 自动做了一半）。

### E. 终端 UX（本项目最贵的学费，占四成 token）
- **E1 CJK 占 2 列，且只准一张宽度表。**
  ⚡ 全角冒号 `：`、全角空格都是 2 列；两张表不一致 = 列歪。
  ✅ `display_width()` 全项目唯一，padding/截断全走它。
- **E2 填充目标必须 ≥ 最大显示宽度。**
  ⚡ off-by-one：最长那行溢出 1 列，把后面所有列顶歪，截图找半天。
  ✅ 写完列表先造一条"最长 CJK 数据"验证对齐。
- **E3 别信半高块字符 `▀▄`。**
  ⚡ 部分终端/web 终端字体把它画残，二维码直接失真。
  ✅ 关键图形留"只用 `█`+空格"的退路，做成配置（half/block）。
- **E4 颜色过 light/dark 两关。**
  ⚡ 淡色 dark 下看不见、亮色 light 下晃眼，来回调了 N 轮。
  ✅ 拿不准就用**加粗**不用背景色；两种主题各截一张图再提交。
- **E5 固定 UI 永不让位。**
  ⚡ 一条长备份路径把底部快捷键栏挤出屏幕。
  ✅ 状态消息家目录缩写 `~` + 中间截断，给固定栏让路。
- **E6 锦上添花不挡主路。**
  ✅ 天气/宠物/黄历全后台线程 + 缓存 + 离线静默降级，主命令零等待。

### F. 协作
- **F1 给用户"粘贴即执行"的命令块。** ✅ git 发布、安装升级都整段给，别让用户自己拼。
- **F2 push 被拒先查 ruleset，别盲目重试。** ✅ 报错里的 rules 链接就是答案。

## 🗂 本项目档案（mfacli 专属决策）

| 主题 | 决策 | 为什么 |
|------|------|--------|
| 形态 | CLI 默认、`mfa tui` 进 TUI，功能对齐 | 可脚本化是差异化卖点 |
| Linux 分发 | 首推 musl 静态包 | gnu 版在老 glibc 挂（CentOS7 报 GLIBC_2.29 缺失） |
| 压缩包 | 含顶层同名目录 | 解压不弄乱当前目录 |
| 二维码 | half 默认 / block 兼容，可配置 | 终端字体差异，两种都做过反解验证 |
| 冲突策略 | add/scan/import 统一 `-c ask/rename/skip/overwrite` | 三处行为一致，批量重导可强制覆盖 |
| 寻址 | 名称 + 序号（01 补零）双轨 | 敲名字和指序号都顺手，删除支持批量 |
| filter | `\|` 或、`*` 通配、`^/$` 锚点、忽略大小写 | 不引 regex crate，保持小而美 |
| KDF | Argon2id 64MiB / 3 pass / p=4，参数存密文头 | OWASP 推荐参数 + 防篡改 |
| 天气 | wttr.in + 国内 DNS 优先探测 + 30 分钟缓存 + 无城市名显示「IP定位」 | 国内可用、不阻塞、不显示裸坐标 |
| 新条目 | ✦ 标记 ≤7 天，ADDED 列宽屏才显示 | 提醒到位但不吵 |

## 🕳 踩坑速查表

| 症状 | 原因 | 解法 |
|------|------|------|
| `GLIBC_2.xx not found` | gnu 构建上老系统 | 换 musl 静态包 |
| tag push 被拒 | ruleset 限制 / tag 已存在 | 清 ruleset 或 bump 版本 |
| 二维码失真 | 字体缺半高块字形 | `config --qr-style block` |
| 表格列歪 | CJK 宽度 / off-by-one | 统一宽度表 + 填充 ≥ 最大宽 |
| `yes` 确认误取消 | 退格字符混入 | 读取时过滤 `\x7f` `\x08` |
| 提示出现在输入后 | `print!` 没 flush | 跟一个 `flush()` |
| example 离线编译失败 | lock 孤儿包 + 缓存缺 crate | 删 dev-deps + `cargo update --offline` |
| 中文字符串切片 panic | 按字节切到字符中间 | `get(..n)` 或宽度函数 |
